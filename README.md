# 課堂互動簡報產生器 (Classroom Presentation Slides Generator) 🎓

> **極致簡約 ‧ 滿版沉浸 ‧ 課堂互動大屏友善**  
> 專為中小學教師、特教資源班、SEL 社交情緒課程打造的單一自包含 HTML 課堂簡報產生規範與模板。

---

## 🌟 核心特點

1. **極簡滿版舞台（100vw × 100vh）**：
   - 零頂部/底部干擾導覽條，專注大螢幕與投影機教學。
   - 溫潤暖米色底（`#f4efe6`）搭配細緻半透明有機柔光氛圍氣泡。
2. **右下角懸浮藥丸控制盒（Minimalist Pill Controller）**：
   - 固定於右下角，預設半透明（`opacity: 0.32`），完全不遮擋投影片文字。
   - 滑鼠懸停平滑浮現至 100%（`opacity: 1`），精簡保留 `‹  X / Y  ›  |  ⊞ (九宮格目錄)  ⛶ (全螢幕)`。
3. **零 Emoji 雜訊**：
   - 嚴格去除所有干擾性 Emoji 圖示，遮罩顯答為純淨灰底「點擊顯答」，步驟與標題以中文序號優雅呈現。
4. **全方位快捷鍵與實體翻頁筆支援**：
   - `← / → / Space / P / N`：無感前後換頁。
   - `A`：一鍵揭曉／隱藏當頁所有遮罩答案。
   - `V`：Web Speech 智慧語音示範朗讀（台灣腔 `zh-TW`）。
   - `O`：九宮格章節總覽目錄彈窗。
   - `B`：課堂即時黑屏。
   - `F`：全螢幕切換。
5. **黃金版面結構**：
   - **封面**：巨大課程代號 `L1`（暖橘色 `#e07a42`）＋ 標題 ＋ 左下方章節導航卡片。
   - **教學頁**：左欄 3D/實境情境圖與描述 ＋ 右欄 4 步驟拆解與互動遮罩顯答。
   - **總結頁**：通關總結 ＋ 實踐 3 大要訣 ＋ 彩帶慶祝特效。

## 🚀 快速安裝與使用

### 作為 Antigravity / Claude Code / Cursor Skill 使用

將本儲存庫複製至你的專案 `.agents/skills/classroom-presentation-slides` 目錄下：

```bash
git clone https://github.com/chuoneone/classroom-presentation-slides.git .agents/skills/classroom-presentation-slides
```

當在對話中提及以下關鍵字時，AI Agent 將自動啟動此 Skill：
- 「課堂簡報」、「互動簡報」、「上課簡報」、「簡報模式」、「教學投影片」、「情境簡報」

## ⌨️ 快捷鍵一覽

| 快捷鍵 | 功能描述 |
| :--- | :--- |
| `→` / `Space` / `PageDown` / `N` | 下一頁投影片 |
| `←` / `PageUp` / `P` | 上一頁投影片 |
| `A` | 一鍵揭曉／隱藏當頁所有遮罩答案 |
| `V` | Web Speech 語音示範朗讀 |
| `O` | 開啟／關閉九宮格章節目錄 |
| `B` | 課堂黑屏模式（按任意鍵或點擊退出） |
| `F` | 全螢幕模式切換 |
